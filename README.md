# Dotfiles

[![lint](https://github.com/jan-xyz/Dotfiles/actions/workflows/lint.yaml/badge.svg)](https://github.com/jan-xyz/Dotfiles/actions/workflows/lint.yaml)

My personal macOS setup.

## Configuration for

* Neovim
* fish
* Ghostty and kitty
* git
* starship
* fzf
* Hammerspoon
* Homebrew packages, Mac App Store apps, and VS Code extensions (`Brewfile`)
* macOS system preferences (`macos.sh`)

## Install

```sh
./install.sh
```

or

```sh
make install
```
